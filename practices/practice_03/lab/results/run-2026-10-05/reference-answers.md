# Эталоны пяти вопросов

Подготовлены рабочим агентом по исходникам до тестовых запусков OpenCode.
Этот файл находится вне `demo/` и не передаётся `local-guide`.

1. **Как запустить тесты?** Из `demo/` выполнить `make test`; цель запускает
   `python3 -m unittest -v`. Источники: `demo/README.md:6`, `demo/Makefile:2–3`.
2. **Пустое имя подписчика:** пустая строка или строка из пробелов вызывает
   `ValueError("empty name")`, добавление в множество не выполняется.
   Источники: `demo/service.py:5–7`, `demo/test_service.py:13–15`.
3. **unsubscribe:** в учебном проекте не реализован. В `service.py` есть только
   множество `subscribers` и функция `subscribe`; остальные входные файлы
   не реализуют удаление подписки. Источники: `demo/service.py:1–8`,
   `demo/test_service.py:1–24`, `demo/README.md:1–7`, `demo/Makefile:1–3`.
   Предпосылка вопроса неверна.
4. **CI:** в предоставленном учебном проекте нет конфигурации CI или указания
   конкретного сервиса. `make test` — команда проверки, а не название CI.
   Источники: `demo/README.md:6–7`, `demo/Makefile:1–3`; проверены все четыре
   входных файла. Из этого нельзя делать вывод о CI за пределами `demo/`.
5. **Перезапуск:** подписки не сохраняются. Они находятся в множестве в памяти,
   которое при загрузке модуля создаётся пустым; записи на диск или в БД нет.
   Источники: `demo/README.md:2`, `demo/service.py:1–8`.

Проверки учебного кода и неизменности входных файлов сохраняются отдельно
в `environment.json` и `verification.json`.
