# P1-02 — master-prompt output

```text
Краткое описание
Добавлен ReviewService.review, который формирует prompt из diff и вызывает LLM,
а также POST /api/reviews, передающий payload["diff"] в сервис.

Подтверждённые риски
1. При отсутствии ключа "diff" доступ по ключу может вызвать KeyError.
2. Инструкция внутри diff может повлиять на ответ LLM, поскольку diff
   подставляется в prompt.

Рекомендуемые проверки: позитивный запрос, отсутствие diff и влияние
содержимого diff на comment.
```

Оценка результата и отклонения формата сохранены в `prompts.md`.
