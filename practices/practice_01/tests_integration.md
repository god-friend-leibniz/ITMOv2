# Integration-проверки

| Связь компонентов | Что может сломаться | Как воспроизводим | Ожидаемый результат | Подтверждение |
|---|---|---|---|---|
| API /api/reviews → ReviewService → LLM-заглушка | Неверная инъекция зависимости, несоответствие типов, сериализация | Подменить зависимость review_service на экземпляр с LLM-заглушкой; отправить POST /api/reviews с JSON {"diff": "some diff"} | Ответ — JSON с ключом "comment" (строка), значение совпадает с ответом заглушки | Вызвать endpoint тестовым клиентом/напрямую; проверить, что тело ответа содержит строковый "comment" с ожидаемым значением |
| API /api/reviews при отсутствии ключа "diff" | Неконтролируемая ошибка вместо диагностируемого ответа | Отправить POST /api/reviews с телом {} | Возвращается контролируемая диагностируемая ошибка, указывающая на отсутствие `diff`; ключ `comment` отсутствует | Проверить тело ответа на диагностическое указание отсутствующего `diff` и отсутствие `comment`; не требовать конкретного статуса |
| API → Service передаёт prompt дословно с многострочным diff | Потеря переводов строк или искажение содержимого | Отправить {"diff": "line1\nline2"} с LLM-заглушкой, которая записывает полученный prompt | Заглушка получает prompt "Review this pull request and find problems:\nline1\nline2" | Проверить зафиксированный prompt в заглушке, что он равен ожидаемому |
