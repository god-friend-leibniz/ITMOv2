# План поставки

## Инкременты и ответственность

| Инкремент | Наблюдаемый результат | Что делает человек | Что делает AI или субагент | Проверка | Зависимости |
|---|---|---|---|---|---|
| 1. Скелет синхронного сценария | `POST /api/reviews` с валидным `{"diff": "<строка>"}` возвращает JSON с ключом `comment` (при использовании мок-реализации LLM). | Утверждает контракт входа/выхода и формулировку промпта; проводит ручной вызов эндпоинта и фиксирует результат. | Подготавливает черновик сервиса и обработчика согласно diff; предоставляет мок LLM и примеры вызова. | Отправить валидный запрос и убедиться, что в ответе есть строковый `comment`. | — |
| 2. Подключение LLM-клиента за интерфейсом | При доступном LLM клиенте ответ содержит строковый `comment` для валидного diff; базовые вызовы успешны. | Определяет используемый LLM-клиент и параметры окружения [нужно назначить]; проводит пробные вызовы и фиксирует показатели. | Реализует адаптер LLM под протокол; готовит инструкции по конфигурированию. | N вызовов с валидным diff: доля успешных ответов > 0, ответы содержат `comment`; замерено время получения черновика. | 1 |
| 3. Приёмка и отрицательные сценарии | При отсутствии `diff` сервис возвращает контролируемую диагностируемую ошибку без `comment`; сценарий принят. | Выполняет негативные проверки (`{}` без `diff`), фиксирует наблюдаемые результаты; принимает решение о готовности к использованию. | Готовит шаги проверки и шаблон отчёта; помогает собрать результаты. | `POST /api/reviews` с `{}` содержит диагностическое указание отсутствующего `diff` и не содержит `comment`; отчёт по проверке риска оформлен. | 1, 2 |

## Диаграмма Ганта

```mermaid
gantt
    title План первого рабочего сценария
    dateFormat  YYYY-MM-DD

    section Реализация
    И1: i1, [нужно назначить], [нужно назначить]

    section Интеграция
    И2: i2, after i1, [нужно назначить]

    section Приёмка
    И3: i3, after i2, [нужно назначить]
```

## Как использовали AI

- Для чего: подготовить черновик плана из трёх инкрементов с проверками и зависимостями.
- Тип промпта: Master Prompt v4 для ADR и плана поставки.
- Строка в [`prompts.md`](prompts.md): P1-05.
- Что проверил студент и какие исправления поручил агенту: план не выходит за границы первого сценария; проверки наблюдаемы; неизвестные даты/ответственные помечены `[нужно назначить]`.
